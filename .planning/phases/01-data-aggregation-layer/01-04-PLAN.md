**CoordinateMatcher.hpp:**
```cpp
#pragma once
#include <string>
#include <cmath>

namespace astrocore {

class CoordinateMatcher {
public:
    // Match threshold in arcseconds (per user decision: 5 arcsec)
    static constexpr double DEFAULT_THRESHOLD_ARCSEC = 5.0;

    // Check if two star names refer to the same object
    // Normalizes: lowercase, strip whitespace, treat hyphens and spaces as equivalent
    static bool nameMatch(const std::string& name1, const std::string& name2);

    // Compute great-circle distance between two RA/Dec positions in arcseconds
    // Uses haversine formula. Handles RA wrapping at 0/360 correctly.
    static double angularDistance(double ra1_deg, double dec1_deg,
                                  double ra2_deg, double dec2_deg);

    // Check if two positions are within threshold
    static bool withinThreshold(double ra1_deg, double dec1_deg,
                                 double ra2_deg, double dec2_deg,
                                 double threshold_arcsec = DEFAULT_THRESHOLD_ARCSEC);

    // Name-first matching with coordinate fallback (per user decision)
    // Returns true if names match OR coordinates within threshold
    static bool isMatch(const std::string& name1, double ra1_deg, double dec1_deg,
                         const std::string& name2, double ra2_deg, double dec2_deg,
                         double threshold_arcsec = DEFAULT_THRESHOLD_ARCSEC);

    // Normalize a star name for comparison
    static std::string normalizeName(const std::string& name);
};

}  // namespace astrocore
```

**CoordinateMatcher.cpp:**

1. **normalizeName():**
   - Convert to lowercase
   - Replace hyphens with spaces
   - Trim leading/trailing whitespace
   - Collapse multiple spaces to single space
   - This handles "Kepler-442" == "kepler 442" == "KEPLER-442"

2. **nameMatch():** Compare normalizeName(name1) == normalizeName(name2). Both must be non-empty.

3. **angularDistance():** Haversine formula using GLM for trig:
   ```cpp
   double ra1_rad = glm::radians(ra1_deg);
   double dec1_rad = glm::radians(dec1_deg);
   double ra2_rad = glm::radians(ra2_deg);
   double dec2_rad = glm::radians(dec2_deg);
   double delta_ra = ra2_rad - ra1_rad;
   double delta_dec = dec2_rad - dec1_rad;
   double a = std::sin(delta_dec/2) * std::sin(delta_dec/2) +
              std::cos(dec1_rad) * std::cos(dec2_rad) *
              std::sin(delta_ra/2) * std::sin(delta_ra/2);
   double c = 2 * std::atan2(std::sqrt(a), std::sqrt(1-a));
   return glm::degrees(c) * 3600.0; // degrees to arcseconds
   ```
   Note: haversine naturally handles RA wrapping at 0/360 because sin/cos are periodic.

4. **withinThreshold():** Return `angularDistance(...) <= threshold_arcsec`. Handle case where both RA/Dec are NaN (return false).

5. **isMatch():** Try nameMatch first (fast path). If no name match, try coordinate match.

```cpp
#pragma once
#include "data/ExoplanetData.hpp"
#include "data/NasaApiClient.hpp"
#include "data/OecClient.hpp"
#include "data/GaiaClient.hpp"
#include "data/CdsClient.hpp"
#include "data/CacheManager.hpp"
#include <memory>
#include <future>

namespace astrocore {

class DataFusionEngine {
public:
    DataFusionEngine();
    ~DataFusionEngine();

    // Main entry point: fetch and fuse data for a planet from all sources
    std::future<ExoplanetData> fetchAndFuse(const std::string& planetName);
    ExoplanetData fetchAndFuseSync(const std::string& planetName);

    // Pre-fetch top N planets for offline browsing (per user decision: 500)
    std::future<std::vector<ExoplanetData>> prefetchNotable(int count = 500);

    // Get from cache (offline mode)
    std::optional<ExoplanetData> getFromCache(const std::string& planetName);

    // ---- Static fusion methods (public for unit testing) ----

    // Select best measurement from multiple sources
    template<typename T>
    static MeasuredValue<T> selectBestMeasurement(
        const std::vector<MeasuredValue<T>>& candidates);

    // Get source priority (lower = higher priority)
    // User decision: NASA > Gaia > CDS > OEC
    static int getSourcePriority(DataSource source);

    // Merge host star data from multiple sources
    static HostStarData mergeHostStarData(const std::vector<HostStarData>& sources);

    // Merge complete ExoplanetData from multiple sources
    static ExoplanetData mergeExoplanetData(const std::vector<ExoplanetData>& sources);

private:
    struct Impl;
    std::unique_ptr<Impl> m_impl;
};

}  // namespace astrocore
```

**DataFusionEngine.cpp:**

1. **Impl struct:** Holds owned instances of all 4 clients + CacheManager:
   ```cpp
   struct DataFusionEngine::Impl {
       NasaApiClient nasa;
       OecClient oec;
       GaiaClient gaia;
       CdsClient cds;
       CacheManager cache{"fused"};  // .cache/fused/
   };
   ```

2. **getSourcePriority():** Per user decision:
   - NASA_TAP -> 1
   - GAIA -> 2
   - CDS_VIZIER -> 3
   - OEC -> 4
   - CALCULATED -> 5
   - AI_INFERRED -> 6
   - EXOATMOS -> 3 (same as CDS)
   - UNKNOWN -> 999

3. **selectBestMeasurement():** Template function (define in header or .cpp with explicit instantiations for double and std::string):
   - Filter to values where hasValue() is true
   - If empty, return default MeasuredValue
   - If only one, return it
   - Sort by: (a) has uncertainty beats no uncertainty, (b) lower uncertainty wins, (c) tie-break by source priority
   - Return the best

4. **mergeHostStarData():**
   - For each MeasuredValue field in HostStarData, collect all candidates from the sources vector
   - Call selectBestMeasurement for each field
   - For string fields (name, spectral_type), use first non-empty value by source priority
   - Return merged HostStarData

5. **mergeExoplanetData():**
   - Start with the NASA record as base (highest priority)
   - Collect all HostStarData sources, merge via mergeHostStarData
   - For each MeasuredValue field on ExoplanetData, collect candidates and select best
   - For string fields (name, discovery_method), prefer NASA
   - Call calculateDerivedValues() on the merged result

6. **fetchAndFuseSync():**
   - Check fused cache first
   - Query NASA by planet name (sync) -> get base ExoplanetData
   - Query OEC by planet name (sync) -> get supplemental data
   - Use CDS to resolve host star name -> get coordinates
   - Query Gaia by coordinates -> get stellar enrichment
   - Query CDS for VizieR enrichment
   - Collect all results, call mergeExoplanetData
   - Store fused result in CacheManager
   - Return fused ExoplanetData

7. **prefetchNotable():** Query NASA for top N planets (by discovery date or notability), then fuse each. This runs async and can take minutes for 500 planets. Use thread pool or sequential async.

**CacheManager.hpp:**
```cpp
#pragma once
#include "data/ExoplanetData.hpp"
#include <string>
#include <optional>
#include <vector>

namespace astrocore {

class CacheManager {
public:
    explicit CacheManager(const std::string& subdirectory = "fused",
                          const std::string& base_directory = ".cache",
                          int ttl_days = 30);

    // Store a fused ExoplanetData record
    bool store(const std::string& planetName, const ExoplanetData& data);

    // Retrieve a cached record (returns nullopt if missing or expired)
    std::optional<ExoplanetData> retrieve(const std::string& planetName);

    // Check if a record is cached and not expired
    bool isCached(const std::string& planetName);

    // List all cached planet names
    std::vector<std::string> listCached();

    // Clear expired entries
    void clearExpired();

    // Clear all cache
    void clearAll();

private:
    std::string m_cacheDir;
    int m_ttlDays;

    std::string getCachePath(const std::string& planetName) const;
    bool isExpired(const std::string& path) const;
};

}  // namespace astrocore
```

**CacheManager.cpp:**

1. **Constructor:** Build path as `base_directory / subdirectory`. Create directory with `std::filesystem::create_directories`.

2. **getCachePath():** Sanitize planet name (replace spaces with underscores, lowercase) to create filename. Use `.json` extension. Path: `m_cacheDir / sanitized_name.json`.

3. **store():** Serialize ExoplanetData to JSON via `data.toJson()`, write to cache path. Include metadata object at top level:
   ```json
   {
     "metadata": {"cached_at": "2026-02-28T12:00:00", "ttl_days": 30},
     "data": { ... ExoplanetData.toJson() ... }
   }
   ```

4. **retrieve():** Read JSON file, check `metadata.cached_at` + `ttl_days` against current time. If expired, return nullopt. Otherwise parse `data` field via `ExoplanetData::fromJson()`.

5. **isCached():** Check file exists and not expired.

6. **listCached():** Iterate `.json` files in cache directory, return planet names (reverse the sanitization).

7. **clearExpired():** Iterate all cache files, delete those past TTL.
