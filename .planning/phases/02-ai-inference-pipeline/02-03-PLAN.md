   ```python
   df = load_cached_exoplanets(args.cache_dir)
   ```
   If cache is empty or has too few records, generate synthetic test data based on known exoplanet distributions (uniform sampling within physical bounds). Print warning that synthetic data is being used. Target: at least 50 records for meaningful benchmarks.

3. **Defines benchmark tasks:**
   - **Classification task** (BERT): Mask planet_type, predict from mass/radius/temp/density
   - **Structured generation task** (BART): Mask atmosphere_composition + biome_classification, predict from physical params
   - **Numerical imputation task** (TabTransformer, MaskedAutoencoder): Mask mass_earth, radius_earth, equilibrium_temp_k (one at a time), predict from remaining numerical features

4. **Runs mask-predict-evaluate loop for each model:**
   ```python
   def run_benchmark(model, df, task_config):
       """Mask fields, train on complete data, predict masked, measure error."""
       complete = filter_complete_records(df, task_config['required_fields'])
       train_df, test_df = train_test_split(complete, test_size=0.2, random_state=42)

       # Train
       start = time.time()
       model.train(train_df, **task_config['train_kwargs'])
       train_time = time.time() - start

       # Predict on test set with masked target fields
       predictions = []
       inference_times = []
       for idx, row in test_df.iterrows():
           masked = mask_fields(row, task_config['target_fields'])
           t0 = time.time()
           pred = model.predict(masked)
           inference_times.append((time.time() - t0) * 1000)  # ms
           predictions.append(pred)

       # Evaluate
       results = compute_metrics(test_df[task_config['target_fields']], predictions)
       results['train_time_s'] = train_time
       results['avg_inference_ms'] = np.mean(inference_times)
       return results
   ```
