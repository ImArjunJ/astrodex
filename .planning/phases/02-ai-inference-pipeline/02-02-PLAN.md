  <behavior>
**Body type classification (user's locked thresholds):**
- radius_earth < 2.0 -> Terrestrial
- radius_earth 2.0-6.0 -> IceGiant
- radius_earth > 6.0 -> GasGiant
- When radius unavailable, fall back to mass heuristics: mass > 50 M_E -> GasGiant, mass > 10 -> IceGiant, else Terrestrial
- When neither available, default to Terrestrial

**Rayleigh scattering from atmosphere composition:**
- N2/O2 dominant (>50%): Earth blue {5.5e-6, 13.0e-6, 22.4e-6}
- CO2 dominant (>50%): Venus orange {10.0e-6, 6.0e-6, 3.0e-6}
- H2/He dominant (>50%): Pale blue {3.0e-6, 8.0e-6, 15.0e-6}
- No atmosphere data: default to Earth-like
- Invalid JSON: default to Earth-like (no crash)

**Terrestrial surface mapping (multi-factor):**
- effectiveT > 700K (Venus/lava): seaLevel=0, volcanicActivity=0.6, veg=0, dense haze, orange haze color
- effectiveT 350-700K (hot desert): low seaLevel, low moisture, desert colors
- effectiveT 250-350K (habitable): ocean from data or default 0.5, vegetation scales with temperature
- effectiveT 150-250K (cold/Mars-like): no sea, ice extent 0.3, craters, thin haze
- effectiveT < 150K (frozen): full ice, no vegetation, ice colors
- CO2 greenhouse: thick CO2 (>90%) + high pressure (>50 atm) -> T *= 1.8 (Venus analog)
- Moderate CO2 (>10%): T *= (1 + co2/500)

**Gas giant mapping:**
- Band count scales with radius: clamp(R/11.2 * 12, 4, 20)
- Hot Jupiter (T>1000K): muted bands (contrast 0.15), intense storms (0.3), dark colors
- Cold gas giant: high contrast (0.35), fewer storms (0.15), Jupiter-like bright bands
- Great spot probability scales with mass: spotSize = (M/317.8 > 0.5) ? 0.12 * M/317.8 : 0
- IceGiant: similar to cold gas giant but with bluer tint, fewer bands

**Physical properties mapping:**
- radius, mass from data (default 1.0 Earth)
- surfaceGravity from data or mass/radius^2
- surfaceTemp from equilibrium_temp_k
- seed from hash of planet name (reproducible)

**Cloud layers:**
- Terrestrial habitable: 1 cloud layer at altitude 0.02, coverage from data or 0.4
- Venus-like: thick cloud layer, high coverage (0.9), altitude 0.05
- Gas giant: 2 cloud layers at different altitudes
- Frozen: thin wispy clouds, low coverage

**Test cases (input -> expected output):**
- Kepler-442b (R=1.34, T=233K): Terrestrial, cold habitable, some ice, Earth-like Rayleigh
- WASP-12b (R=20.7, T=2580K): GasGiant, hot Jupiter, muted bands, dark colors
- Venus analog (R=0.95, T=232K, CO2=96.5%, P=92atm): Terrestrial, effectiveT=418K after greenhouse, orange haze
- Neptune analog (R=3.88, T=72K, H2=80%,He=19%): IceGiant, pale blue Rayleigh, banded
- Empty data (all NaN): Terrestrial (default), Earth-like defaults, no crash

Key additions beyond the research examples:
- `mapIceGiantParams`: Similar to gas giant but fewer bands (clamp 4-10), bluer tint, Neptune-like
- Cloud layer creation based on body type and temperature
- Seed generation: `std::hash<std::string>{}(data.name)` for reproducibility
- OceanParams population: deep/shallow/coast colors from temperature (warm=green-blue, cold=dark-blue, frozen=gray-blue)

**Step 3: Implement fromObservations(const ExoplanetData&)**

Main flow:
1. Create default params
2. Set name from data
3. Classify body type using user's radius thresholds
4. Set physical properties (radius, mass, gravity, temp)
5. Compute Rayleigh from atmosphere composition
6. Map atmosphere density/height from surface pressure
7. Branch on body type:
   - Terrestrial: mapTerrestrialSurface + mapCloudLayers
   - GasGiant: mapGasGiantParams + mapCloudLayers
   - IceGiant: mapIceGiantParams + mapCloudLayers
8. Set seed from name hash
9. Return params
