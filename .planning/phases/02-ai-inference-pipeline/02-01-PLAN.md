Add a private helper method `applyDeterministicDefaults(ExoplanetData&)` to DataFusionEngine (declare in .hpp or just implement as a free function in .cpp). This fills truly missing (NaN) fields with physics-based defaults:
- albedo: T > 700K -> 0.75 (Venus-like reflective clouds), T 250-700K -> 0.3 (Earth-like), T < 250K -> 0.5 (ice world)
- surface_pressure_atm: based on mass/radius -- large rocky planets retain more atmosphere
- atmosphere_composition: based on temperature and mass (H2/He for gas giants, CO2/N2 for hot rocky, N2/O2 for habitable zone)
- biome_classification: based on temperature zones (Lava World > 700K, Desert 350-700K, Temperate 250-350K, Tundra 150-250K, Ice World < 150K)
- ocean_coverage_fraction, cloud_coverage_fraction, ice_coverage_fraction: temperature-based defaults
All fallback values MUST be marked `DataSource::CALCULATED` (not AI_INFERRED).

Modify `fetchAndFuseSync()` in DataFusionEngine.cpp. After `ExoplanetData fused = mergeExoplanetData(sources);` (line 296), BEFORE `m_impl->cache.store(...)` (line 299), add:

```cpp
// AI inference gap-filling (per user decision: always run after fusion)
if (m_impl->inference.isAvailable()) {
    try {
        fused = m_impl->inference.fillMissingParametersSync(fused);
    } catch (const std::exception& e) {
        LOG_WARN("AI inference failed for '{}': {}, applying rule-based defaults", planetName, e.what());
        applyDeterministicDefaults(fused);
    }
} else {
    LOG_INFO("AI unavailable for {}, using rule-based defaults", planetName);
    applyDeterministicDefaults(fused);
}
```

Per user decision: retry strategy is one retry then fallback. Modify InferenceEngine::inferAtmosphere and inferRenderHints to do one retry with a 2-second delay before returning failure. Add retry logic inside each method:
```cpp
auto response = m_bedrock->inferSync(request);
if (!response.success) {
    LOG_INFO("Retrying inference for {} after transient failure", data.name);
    std::this_thread::sleep_for(std::chrono::seconds(2));
    response = m_bedrock->inferSync(request);
}
```
