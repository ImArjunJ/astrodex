Create `CatalogueView` class as a new UI module following the pattern from `GalaxyView`. Implements Pokedex-style card grid layout with placeholder cards (no thumbnails yet — just colored rectangles representing planet types).

**CatalogueView.hpp:**
- Class declaration with public methods: `init()`, `render(const std::vector<ExoplanetData>&, float W, float H)`, `setPlanetCallback(std::function<void(const std::string&)>)`, `setLoadingProgress(int current, int total)`
- Private state: filter settings (planet type enum set, habitable zone bool), sort mode enum (DiscoveryDate, Mass, Radius, Name), sort direction bool, search buffer (char[256]), filtered/sorted indices vector
- Private methods: `renderSearchBar()`, `renderFilters()`, `renderSortControls()`, `renderCardGrid()`, `applyFiltersAndSort()`, `onCardClicked(int idx)`
- Filter types: All, Terrestrial, GasGiant, IceGiant, SuperEarth (from ExoplanetData::planet_type)

**CatalogueView.cpp:**
- **renderCardGrid():** ImGui::BeginChild scrollable region, manual grid layout with dynamic column count based on available width. Card size 200×280px (Claude's discretion per CONTEXT.md). Each card: colored background based on planet type (Terrestrial=brown, GasGiant=orange, IceGiant=blue, SuperEarth=green), planet name text, discovery year text, key stat (mass or radius if available), "Data incomplete" indicator if critical fields missing (hasValue() checks). Use ImGui::InvisibleButton for click detection covering entire card. Placeholder rectangle uses ImDrawList::AddRectFilled with planet-type color and 8px corner rounding.
- **renderSearchBar():** ImGui::InputText with autocomplete dropdown (reuse pattern from UIManager::render exoplanet search). Filter matches planet names by prefix (case-insensitive). Only search within current filtered set.
- **renderFilters():** Horizontal chip layout (ImGui::Selectable in same line, spacing between). Chips: "All", "Terrestrial", "Gas Giant", "Ice Giant", "Super-Earth", "Habitable Zone" (toggle). Clicking a chip updates filter state and triggers `applyFiltersAndSort()`.
- **renderSortControls():** ImGui::Combo dropdown with options: "Discovery Date ↓", "Discovery Date ↑", "Mass ↓", "Mass ↑", "Radius ↓", "Radius ↑", "Name A-Z", "Name Z-A". Default: "Discovery Date ↓" (newest first per CONTEXT.md).
- **applyFiltersAndSort():** Build filtered index vector from input data (check planet_type string match, habitable zone via semi_major_axis_au vs host star luminosity calculation). Sort filtered indices by selected criterion. Store in m_filteredIndices.
- **render():** Top bar with search + filters + sort (horizontal layout). Below: loading progress if provided ("Loading... 142/500 planets" centered text). Below: card grid via renderCardGrid(). Match UIManager theme (dark/light) by reading ImGui style colors.
- **onCardClicked():** Invoke registered callback with planet name. Catalogue should remain visible (no automatic hide) — Application handles transition.

**Planet type color mapping (placeholder cards):**
- Terrestrial: RGB(139, 90, 60) — brown/rocky
- Gas Giant: RGB(255, 140, 60) — orange/Jupiter-like
- Ice Giant: RGB(100, 180, 255) — blue/Neptune-like
- Super-Earth: RGB(80, 200, 120) — green/Earth-like
- Unknown: RGB(120, 120, 120) — gray

**Habitable zone calculation (simple version for filter):**
- HZ inner edge = sqrt(host_star.luminosity_solar.value) * 0.95 AU
- HZ outer edge = sqrt(host_star.luminosity_solar.value) * 1.67 AU
- Planet in HZ if semi_major_axis_au.value is between inner and outer
- If luminosity missing, skip HZ filter for that planet
