Integrate ThumbnailRenderer into the catalogue: progressively generate planet thumbnails in the background, cache them as PNGs for instant reload, display them in catalogue cards, and implement hover-to-animate (slow rotation of one planet at a time). Purpose: Elevate the catalogue from placeholder cards to a visually rich Pokedex-style browser where users can see each planet's appearance before clicking. Thumbnails persist across sessions for instant catalogue loading.

Output: Catalogue cards display real planet thumbnails. Hovering animates the planet with slow rotation. Thumbnails are progressively generated in background (visible cards first). PNG cache ensures instant reload on subsequent launches. Manual checkpoint to verify thumbnail quality and decide on resolution (128px vs 256px).

<task type="auto">
  <name>Task 2: Implement progressive thumbnail generation and caching</name>
  <files>src/core/Application.cpp</files>
  <action>
Wire thumbnail generation into Application lifecycle: create ThumbnailRenderer, load cached PNGs on startup, progressively render missing thumbnails in background, save to disk cache, and handle hover animation.

**Application::init() additions:**
- After creating m_renderer (VulkanRenderer), get Vulkan resources and create ThumbnailRenderer:
```cpp
// Extract Vulkan handles from renderer (assuming VulkanRenderer exposes these; may need getter methods)
VkDevice device = m_renderer->getDevice();
VmaAllocator allocator = m_renderer->getAllocator();
VkQueue queue = m_renderer->getGraphicsQueue();
VkCommandPool cmdPool = m_renderer->getCommandPool();

m_thumbnailRenderer = std::make_unique<ThumbnailRenderer>(device, allocator, queue, cmdPool, 128);
```
- Create ExoplanetMapper: `m_exoMapper = std::make_unique<ExoplanetMapper>();` (if not already created in prior phases)
- Create thumbnail camera with fixed position (frames a unit sphere at distance 3): `m_thumbnailCamera = std::make_unique<Camera>(); m_thumbnailCamera->setPosition(glm::vec3(0, 0, 3)); m_thumbnailCamera->lookAt(glm::vec3(0, 0, 0));`
- Call `loadThumbnailsFromCache();` to preload existing thumbnails from disk

**loadThumbnailsFromCache() implementation:**
- Use `std::filesystem::directory_iterator` to scan `.cache/thumbnails/` for *.png files
- For each PNG, extract planet name from filename (e.g., "kepler-186f.png" → "kepler-186f"; use slug format: lowercase, hyphens)
- Call `loadPNGAsTexture(filepath)` to upload PNG to GPU as VkImage and register with ImGui
- Store result in m_catalogue via `m_catalogue->setThumbnail(planetName, texID);`
- If .cache/thumbnails/ doesn't exist, create it: `std::filesystem::create_directories(".cache/thumbnails");`

**loadPNGAsTexture() implementation:**
- Use stb_image.h to load PNG: `int w, h, ch; uint8_t* pixels = stbi_load(filepath.c_str(), &amp;w, &amp;h, &amp;ch, 4);`
- Create VkImage (same format as ThumbnailRenderer color attachment: VK_FORMAT_R8G8B8A8_UNORM), allocate GPU memory via VMA
- Create staging buffer, copy pixels to staging, transition image to TRANSFER_DST, copy buffer to image, transition to SHADER_READ
- Create VkImageView and VkSampler, register with ImGui: `ImTextureID texID = ImGui_ImplVulkan_AddTexture(sampler, view, VK_IMAGE_LAYOUT_SHADER_READ_ONLY_OPTIMAL);`
- Free stbi pixels: `stbi_image_free(pixels);`
- Return texID

**Application::update() additions (thumbnail generation loop):**
- **Queue initialization:** After prefetch completes and m_catalogueData is populated, initialize thumbnail queue with all planet indices: `for (int i = 0; i < m_catalogueData.size(); ++i) { m_thumbnailQueue.push_back(i); }`
- **Visible card prioritization:** Query CatalogueView for visible card indices (via scroll position), move those to front of queue. This is Claude's discretion; simple heuristic: if user is viewing catalogue, render cards in display order.
- **Progressive rendering (one per frame):** If not currently rendering and queue not empty:
```cpp
if (!m_renderingThumbnail &amp;&amp; !m_thumbnailQueue.empty()) {
    m_currentThumbnailIdx = m_thumbnailQueue.front();
    m_thumbnailQueue.pop_front();

    // Check if thumbnail already exists (from cache)
    std::string slug = makePlanetSlug(m_catalogueData[m_currentThumbnailIdx].name);
    std::string cachePath = fmt::format(".cache/thumbnails/{}.png", slug);
    if (std::filesystem::exists(cachePath)) {
        // Already cached, skip rendering (was loaded in init)
        continue; // Actually, we need to loop, so set flag and return
    }

    // Launch async render
    m_thumbnailFuture = std::async(std::launch::async, [this, idx = m_currentThumbnailIdx]() {
        const auto&amp; planet = m_catalogueData[idx];

        // Convert ExoplanetData to PlanetParams
        PlanetParams params;
        if (planet.radius_earth.hasValue() &amp;&amp; planet.mass_earth.hasValue()) {
            params = m_exoMapper->mapToParams(planet);
        } else {
            // Fallback: use analog from SolarSystemDatabase
            params = SolarSystemDatabase::findClosestAnalog(planet);
        }

        // Render thumbnail
        ImTextureID texID = m_thumbnailRenderer->renderThumbnail(params, *m_thumbnailCamera);

        // Save to PNG cache
        std::string slug = makePlanetSlug(planet.name);
        std::string pngPath = fmt::format(".cache/thumbnails/{}.png", slug);
        m_thumbnailRenderer->saveToPNG(pngPath);

        return texID;
    });

    m_renderingThumbnail = true;
}
```
- **Poll async result:** If rendering, check if future is ready: `if (m_renderingThumbnail &amp;&amp; m_thumbnailFuture.wait_for(0ms) == std::future_status::ready) { ImTextureID texID = m_thumbnailFuture.get(); m_catalogue->setThumbnail(m_catalogueData[m_currentThumbnailIdx].name, texID); m_renderingThumbnail = false; }`

**Hover animation (slow rotation):**
- Query hovered card index from CatalogueView: `int hoveredIdx = m_catalogue->getHoveredCardIndex();`
- If hoveredIdx != -1 and not rendering that planet's thumbnail currently:
  - Get planet params
  - Update rotationOffset based on elapsed time: `params.rotationOffset += deltaTime * 0.1f;` (10 sec per full rotation)
  - Re-render thumbnail: `m_thumbnailRenderer->renderThumbnail(params, *m_thumbnailCamera);` (synchronously, in main thread, since it's just one per frame)
  - Update texture in catalogue: `m_catalogue->setThumbnail(planetName, m_thumbnailRenderer->getImGuiTexture());`
- Do NOT save hover animation frames to PNG cache (only save static snapshots)

**Helper: makePlanetSlug():**
- Convert planet name to filesystem-safe slug: lowercase, replace spaces with hyphens, remove non-alphanumeric (except hyphens)
- Example: "Kepler-186 f" → "kepler-186-f"
