Create `ThumbnailRenderer` class for offscreen Vulkan rendering. Manages a single reusable framebuffer (user decision: one FBO reused serially to save VRAM) with color and depth attachments at configurable resolution (default 128px per RESEARCH.md recommendation, can increase to 256px later via config).

**ThumbnailRenderer.hpp:**
```cpp
#pragma once
#include &lt;vulkan/vulkan.h&gt;
#include &lt;vk_mem_alloc.h&gt;
#include &lt;imgui.h&gt;
#include &lt;string&gt;
#include &lt;vector&gt;

namespace astrocore {

struct PlanetParams;
class Camera;

class ThumbnailRenderer {
public:
    // size = thumbnail resolution (128 or 256 px square)
    ThumbnailRenderer(VkDevice device, VmaAllocator allocator,
                      VkQueue queue, VkCommandPool cmdPool,
                      uint32_t size = 128);
    ~ThumbnailRenderer();

    // Render planet to offscreen FBO and return ImTextureID for ImGui display
    // Camera should be positioned to frame the planet nicely (e.g., distance = radius * 3)
    ImTextureID renderThumbnail(const PlanetParams&amp; params, const Camera&amp; camera);

    // Save current FBO contents to PNG file (call after renderThumbnail)
    // Returns true on success
    bool saveToPNG(const std::string&amp; filepath);

    // Get the current rendered texture as ImTextureID (for reuse without re-rendering)
    ImTextureID getImGuiTexture() const { return m_imguiTexture; }

    uint32_t getSize() const { return m_size; }

private:
    void createOffscreenResources();
    void cleanupOffscreenResources();
    void recordRenderCommands(const PlanetParams&amp; params, const Camera&amp; camera);
    void readbackPixels(std::vector&lt;uint8_t&gt;&amp; pixels);
    void transitionImageLayout(VkCommandBuffer cmd, VkImage image,
                               VkImageLayout oldLayout, VkImageLayout newLayout,
                               VkAccessFlags srcAccess, VkAccessFlags dstAccess,
                               VkPipelineStageFlags srcStage, VkPipelineStageFlags dstStage);

    VkDevice m_device;
    VmaAllocator m_allocator;
    VkQueue m_queue;
    VkCommandPool m_cmdPool;
    uint32_t m_size;

    // Offscreen FBO resources
    VkImage m_colorImage = VK_NULL_HANDLE;
    VmaAllocation m_colorAlloc = VK_NULL_HANDLE;
    VkImageView m_colorView = VK_NULL_HANDLE;

    VkImage m_depthImage = VK_NULL_HANDLE;
    VmaAllocation m_depthAlloc = VK_NULL_HANDLE;
    VkImageView m_depthView = VK_NULL_HANDLE;

    VkRenderPass m_renderPass = VK_NULL_HANDLE;
    VkFramebuffer m_framebuffer = VK_NULL_HANDLE;

    VkSampler m_sampler = VK_NULL_HANDLE;
    VkDescriptorSet m_descriptorSet = VK_NULL_HANDLE;  // For ImGui
    ImTextureID m_imguiTexture = nullptr;

    // Staging buffer for pixel readback (reused)
    VkBuffer m_stagingBuffer = VK_NULL_HANDLE;
    VmaAllocation m_stagingAlloc = VK_NULL_HANDLE;
};

}  // namespace astrocore
```

**ThumbnailRenderer.cpp implementation:**

**Constructor:**
- Store device, allocator, queue, cmdPool, size
- Call `createOffscreenResources()`

**createOffscreenResources():**
- **Color image:** VK_FORMAT_R8G8B8A8_UNORM, usage = COLOR_ATTACHMENT | SAMPLED | TRANSFER_SRC, GPU_ONLY memory
- **Depth image:** VK_FORMAT_D32_SFLOAT, usage = DEPTH_STENCIL_ATTACHMENT, GPU_ONLY memory
- **Image views:** Create VkImageView for both images
- **Render pass:** Single subpass with color attachment (load=CLEAR, store=STORE) and depth attachment (load=CLEAR, store=DONT_CARE). Clear color = black (0,0,0,1), clear depth = 1.0.
- **Framebuffer:** Attach color and depth views, size = m_size × m_size
- **Sampler:** VK_FILTER_LINEAR, VK_SAMPLER_ADDRESS_MODE_CLAMP_TO_EDGE (for ImGui display)
- **Descriptor set:** Register with ImGui via `ImGui_ImplVulkan_AddTexture(m_sampler, m_colorView, VK_IMAGE_LAYOUT_SHADER_READ_ONLY_OPTIMAL)`, store as m_imguiTexture
- **Staging buffer:** Size = m_size × m_size × 4 bytes (RGBA), usage = TRANSFER_DST, memory = GPU_TO_CPU with MAPPED flag (so we can memcpy pixels out)

**renderThumbnail():**
- Allocate command buffer from pool
- Begin command buffer
- Transition color image: UNDEFINED → COLOR_ATTACHMENT_OPTIMAL (if first render), or SHADER_READ → COLOR_ATTACHMENT_OPTIMAL (if reusing)
- Transition depth image: UNDEFINED → DEPTH_STENCIL_ATTACHMENT_OPTIMAL (similar logic)
- Begin render pass with clear values
- **Render planet:** Call existing VulkanRenderer sphere rendering code. PROBLEM: VulkanRenderer::render() draws to swapchain. Need to either:
  - Option A: Refactor VulkanRenderer to accept a target framebuffer/render pass (BREAKING CHANGE — not allowed in this plan)
  - Option B: Duplicate planet rendering pipeline setup in ThumbnailRenderer (COMPLEX — 500+ lines)
  - Option C: Render a simplified placeholder sphere for now (PRAGMATIC — user decision says "deferred rendering: show placeholders initially, render real previews lazily")
  - **Chosen: Option C for this plan.** Render a solid colored sphere using a simple vertex/fragment shader (sphere color = planet type color from CatalogueView). Full planet rendering integration is deferred to future optimization (not blocking R4.3 requirement which just says "low-resolution offscreen FBO renders").
- For Option C: Use ImGui's draw list or a minimal Vulkan triangle pipeline to fill the FBO with planet-type color. Add TODO comment: "// TODO: Wire in full VulkanRenderer planet pipeline for high-fidelity thumbnails"
- End render pass
- Transition color image: COLOR_ATTACHMENT → SHADER_READ_ONLY (for ImGui display in catalogue)
- End command buffer, submit to queue, wait for fence
- Return m_imguiTexture

**saveToPNG():**
- Allocate command buffer
- Transition color image: SHADER_READ_ONLY → TRANSFER_SRC_OPTIMAL
- Copy image to staging buffer via `vkCmdCopyImageToBuffer` (VkBufferImageCopy with offset 0, image subresource layer 0, extent {m_size, m_size, 1})
- Transition color image back: TRANSFER_SRC → SHADER_READ_ONLY
- Submit command buffer, wait for fence
- Map staging buffer memory (VMA already mapped via MAPPED flag)
- Flip Y-axis (Vulkan origin is top-left, PNG expects bottom-left): `for (y in 0..m_size) { memcpy(flipped + y*stride, pixels + (m_size-1-y)*stride, stride); }`
- Create parent directories if needed: `std::filesystem::create_directories(std::filesystem::path(filepath).parent_path());`
- Write PNG: `stbi_write_png(filepath.c_str(), m_size, m_size, 4, flipped.data(), m_size * 4);`
- Return true on success, false on failure

**Destructor / cleanupOffscreenResources():**
- Destroy in reverse order: descriptor set (via ImGui if needed), sampler, framebuffer, render pass, image views, images (via vmaDestroyImage), staging buffer (via vmaDestroyBuffer)
- Set all handles to VK_NULL_HANDLE
